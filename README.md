# 🚀 Nexus Control

**Turn your iPad into a powerful Linux desktop control panel.**

Nexus Control is a Linux desktop companion that transforms your iPad into a remote control center for your computer. It provides system monitoring, workspace management, media controls, audio controls and more.

## ✨ Features

- 📊 Real-time CPU, RAM and disk monitoring
- 🖥️ Niri workspace management
- 🎵 Media playback controls
- 🔊 Audio volume management
- 🌐 Remote access from iPad
- 🔐 Token-based API authentication
- 🖥️ Desktop management application
- 🔔 System tray integration
- 🎨 Dux Shell 2.0 widget integration

## 📦 Installation

### Arch Linux

1. Download the latest release from [GitHub Releases](https://github.com/halildnm/Nexus-Control/releases/latest).
2. Extract the ZIP archive.
3. Open the extracted folder.
4. Run `install.sh` from your file manager.
5. Open Nexus Control from your application menu.

### iPad Connection

1. Make sure your iPad and Linux computer are connected to the same Wi-Fi network.
2. Start Nexus Control on your computer.
3. Find the computer's local IP address in the desktop application.
4. Open the displayed address on your iPad.

## 🖥️ Desktop Integration

### Niri

Nexus Control includes a desktop launcher and supports system tray integration through a StatusNotifierItem-compatible tray host.

### Dux Shell 2.0

A dedicated widget is included for Dux Shell 2.0.

The widget displays connection status and CPU usage and provides quick access to the Nexus dashboard.

## 🔧 Technology

- Python
- FastAPI
- PySide6
- QML
- Dux Shell
- Linux / Niri

## 🔒 Security

Nexus Control uses token-based authentication.

Do not expose the service directly to the public internet. Use it on trusted local networks.
